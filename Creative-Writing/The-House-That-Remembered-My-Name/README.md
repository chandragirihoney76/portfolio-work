# The House That Remembered My Name

A three-part psychological mystery / supernatural fiction series centered around Daniel Carter and the mysterious Blackwood House.

## Parts

- **Part I — The Invitation**
- **Part II — The Rooms That Shouldn't Exist**
- **Part III — Room Thirteen**

## Themes

Memory, identity, forgotten histories, recurring realities, and the unsettling relationship between Daniel and Blackwood House.

## Portfolio Note

This folder contains the complete three-part creative-writing project. The PDF manuscripts are kept together as one portfolio piece to make the work easy for reviewers, recruiters, and collaborators to explore.
